## 🙋 Sobre Mim

Desenvolvedor Full Stack com 2 anos de experiência, apaixonado por criar soluções web modernas e escaláveis. Tenho foco em JavaScript, TypeScript, React, Node.js e uma constante busca por evoluir tecnicamente e profissionalmente.

Graduado em Desenvolvimento Web Full Stack pela [Trybe](https://www.betrybe.com/) (Turma 20B – Fev/2023), onde desenvolvi habilidades técnicas avançadas e soft skills como trabalho em equipe, comunicação e resolução de problemas.

Durante minha jornada, já atuei com:

- **Frontend:** React.js, Next.js, Tailwind CSS, SASS, Redux
- **Backend:** Node.js, Express, Fastify, TypeScript, Sequelize, Prisma
- **Bancos de dados:** MySQL, PostgreSQL, MongoDB
- **Testes:** Vitest, Jest, RTL, Mocha, Chai, Sinon | TDD
- **Infraestrutura:** Docker, AWS (básico), Heroku
- **Boas práticas:** POO, Design Patterns, Clean Code, Git + GitHub
- **Extras:** ESLint, Zod, JWT, GitHub Actions

Atualmente me aprofundo em **Java**, **Python** e **Rust**.
